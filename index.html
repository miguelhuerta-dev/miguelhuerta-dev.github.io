Sistema Médico con Inteligencia Artificial

Lumina

Sistema integral para clínicas y consultorios que integra inteligencia artificial (Gemini 2.5 Flash) para generar diagnósticos clínicos preliminares y planes nutricionales personalizados. Incluye química sanguínea de 35 elementos, composición corporal, calculadora del Sistema Mexicano de Equivalentes (SMAE), gestión de pacientes, agenda de citas con API REST y autenticación segura con roles.
